To-Do List is a simple and user-friendly website designed to help users organize and manage their daily tasks. It provides a simple interface that allows users to add new tasks, view their task list, and delete tasks when they are no longer needed.
The purpose of this project is to provide an easy way to manage daily tasks, stay organized, and keep track of important activities.
- Add Tasks: Add new tasks to the task list.
- View Tasks: Display all added tasks in an organized list.
- Delete Tasks: Remove unwanted tasks from the list.
- Simple User Interface: Easy-to-use interface for managing tasks.
- HTML5: Used to structure the website.
- CSS3: Used to style the website and design the user interface.
- JavaScript: Used to implement the task management functionality and user interactions.
